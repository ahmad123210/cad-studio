# تحسين أداء وسلاسة محرك الرسم وإضافة مكتبة الفرش والأجهزة المنزلية المعمارية

خطة هندسية شاملة لتسريع محرك الرسم ومنع التقطيع والارتجاف (Zero-Lag 60FPS) أثناء التحريك والسحب والتكبير مع الحفاظ على أعلى درجات الدقة الهندسية، بالإضافة إلى تدشين قسم متكامل للفرش والأجهزة المنزلية والمعمارية (ثلاجة، غسالة، غاز، أسرة، كراسي، طاولات، كنبات، أطقم حمام ومطبخ) بنمط تخطيطي ثنائي الأبعاد مبسط وأنيق وفق المعايير المعمارية العالمية.

---

## مراجعة المستخدم والقرارات المؤكدة (User Review & Confirmed Decisions)

> [!IMPORTANT]
> تم تأكيد التفضيلات والاختيارات الرئيسية في المرحلة الأولى (Phase 1) عبر الاستبيان التفاعلي، وسيتم بناؤها بدقة تامة:

- **القرار المؤكد 1 (مكتبة العناصر والفرش):** إضافة قسم جديد كلياً تحت اسم **"فرش وأجهزة معمارية" (Furniture & Appliances)** يضم تشكيلة متكاملة للأجهزة الكهربائية، غرف النوم، غرف المعيشة، المطبخ، والحمام.
- **القرار المؤكد 2 (أداء وسلاسة الكانفس):** تسريع التحريك (Pan & Zoom & Drag) ومنع التقطيع والارتجاف بشكل نهائي عبر جدولة الإطارات الذكية `requestAnimationFrame`، عزل طبقات الرسم غير المتغيرة، وتسريع خوارزميات الالتقاط (Spatial Box Caching) دون أي مساس بجودة ودقة الرسومات.
- **القرار المؤكد 3 (النمط الرسومي للعناصر):** رسم ثنائي الأبعاد تخطيطي مبسط ومعماري مع خطوط خارجية واضحة ونظيفة (Schematic Clean Line 2D CAD Style)، خفيف جداً على المعالج والذاكرة ويحافظ على وضوح فائق عند التكبير والطباعة والتصدير.

---

## 1. النظرة العامة والمفهوم الأساسي (Overview & Core Concept)

- **ما الذي يقدمه التحديث:**
  1. **محرك تفاعل خالي من التقطيع (Silky Smooth Canvas Engine):** معالجة حركة مؤشر الفأرة وعمليات السحب والتحريك الجماعي (Pan / Drag / Zoom) بحيث تعمل بمعدل 60 إلى 120 إطاراً في الثانية بثبات تام، وتفادي إعادة رسم طبقات الكانفس الثقيلة (Background Layer & Grid Layer) أثناء العمليات العابرة.
  2. **مكتبة فرش وأجهزة منزلية شاملة (14+ رمزاً جديداً):**
     - **المطبخ والأجهزة:** ثلاجة بمقاسين، غسالة ملابس، موقد غاز/فرن، حوض مطبخ مزدوج.
     - **غرف النوم:** سرير مفرد (90×200 سم)، سرير مزدوج كبير (180×200 سم)، خزانة ملابس (دولاب).
     - **غرف المعيشة والاستقبال:** كرسي مفرد/فوتيه، كنبة ثنائية، كنبة ثلاثية، طاولة طعام مستطيلة مع كراسي، طاولة قهوة مستديرة/مستطيلة، مكتب دراسة/عمل مع كرسي.
     - **الحمامات والصحي المعماري:** كرسي مرحاض (WC)، مغسلة يدين، حوض استحمام (بانيو).
  3. **تكامل كامل مع النظام:** إمكانية تدوير العناصر بزوايا حرة أو زوايا سريعة (45° و 90°)، تكبير وتصغير المقياس، التحديد الجماعي، الحذف، التصدير لملفات PNG/PDF/DXF وجدول الكميات (BOQ).

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### مسار المستخدم (User Flow)
1. **فتح مكتبة الرموز:** النقر على تبويب الرموز في الشريط الجانبي أو زر "المكتبة" يظهر تصنيفاً جديداً بترميز لوني مميز: **"فرش وأجهزة" (Furniture)** بأيقونة هندسية معبرة ولون مميز.
2. **المعاينة والاختيار السريع:** تظهر جميع قطع الفرش والأجهزة مع رسومات SVG تخطيطية واضحة ودقيقة توضح المظهر العلوي (Top Plan View) مع أبعادها الحقيقية الافتراضية بالمتر.
3. **الإسقاط الحر على الكانفس:** بمجرد اختيار العنصر، يظهر مخطط العنصر تحت المؤشر بشفافية سلسة وسرعة فائقة دون أي بطء، مع إمكانية وضعه في أي مكان داخل الغرف أو بمحاذاة الجدران.
4. **التحريك والتعديل فائق السلاسة:** تحريك العناصر، تدويرها، أو تحريك لوحة الرسم كاملة (Pan) يتم بسلاسة فورية خالية تماماً من التقطيع (No Stutter).

### النمط البصري والهندسي
- **المخطط الهندسي النظيف:** خطوط خارجية دقيقة بسماكة معيارية متناسقة مع خطوط الجدران والأبواب، مع خلفية شفافة تندمج تماماً مع أرضية المخطط.
- **التوافق اللوني:** تتكيف الخطوط والرموز تلقائياً مع السمة المظلمة (Dark Slate) والسمة الفاتحة (Architectural Blueprint Light).
- **تصميم الواجهة:** خالية من "AI Slop"، أزرار تصنيف نظيفة بدون كبسولات لونية عشوائية، خطوط عربية وهندسية واضحة، وأرقام رقمية متناسقة عمودياً (`tabular-nums`).

## 3. القرارات التقنية ومعالجة الأداء (Technical Strategy & Performance)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   CAD Canvas Performance Architecture                  │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   [ Mouse Movement / Touch / Pan / Zoom ]                              │
│                      │                                                 │
│                      ▼                                                 │
│   ┌──────────────────────────────────────────────────────────────┐     │
│   │ Smart RAF Throttle & Spatial Proximity Filter (Zero Lag)     │     │
│   │ - Throttle mousemove to 1 frame per animation frame          │     │
│   │ - Bounding-box precheck (skip distant objects during snap)   │     │
│   └──────────────────────────────────────────────────────────────┘     │
│                      │                                                 │
│         ┌────────────┴─────────────┐                                   │
│         ▼                          ▼                                   │
│   [Static Layers Cached]    [Active Transient Layer Only]              │
│   - Background Layer        - Interaction Layer (Crosshair/Ghost)      │
│   - Infinite Grid Layer     - Snap Indicator Box                       │
│   - Base Objects Layer      (BatchDraw on RAF - 120 FPS capable)       │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

### الحلول التقنية المعتمدة للسرعة والجودة:
1. **جدولة `requestAnimationFrame` لحركة المؤشر والالتقاط:**
   بدلاً من تنفيذ عمليات حسابية معقدة ورسم الكانفس في كل بكسل يتحركه الماوس مباشرة، يتم تجميع التحديثات عبر متغير راية `rafPending` ليتم الرسم بمعدل تحديث الشاشة الفعلي (60/120Hz)، مما يلغي أي تقطيع أثناء التحريك.
2. **عزل تحديثات الكانفس (Layer Isolation):**
   عند سحب عنصر أو تحريك الفأرة لإسقاط رمز، يتم تحديث `interactionLayer` فقط مع الحفاظ على كاش `objectsLayer` و `gridLayer`، مما يوفر أكثر من 70% من وقت معالجة المعالج (CPU overhead).
3. **تصفية نطاق الالتقاط (Spatial Box Caching):**
   عند فحص الالتصاق والالتقاط (Snapping)، يتم استبعاد العناصر البعيدة عن المؤشر قبل حساب المسافات الهندسية الدقيقة للخطوط والزوايا، ما يضمن أداء ثابتاً حتى مع وجود مئات الجدران والرموز في المشروع.
4. **رسومات متجهة عالية الأداء للرموز الجديدة:**
   كتابة دوال `renderKonva` للرموز الجديدة باستخدام الأشكال الأساسية المحسنة (`Konva.Rect`, `Konva.Circle`, `Konva.Line`) مع تقليل عدد الـ Nodes لكل رمز، لتكون خفيفة جداً وسريعة في التصيير.

## 5. خطوات التنفيذ والتحقق (Execution Roadmap)

1. **الخطوة الأولى: مكتبة الرموز (Symbols Model & Definitions)**
   - إنشاء ملف `src/symbols/furniture.ts` يضم كافة تعريفات الرموز الـ 15 مع دوال `renderKonva` فائقة السرعة وأكواد `svgPreview` مصغرة أنيقة.
   - تحديث `src/symbols/types.ts` لإضافة تصنيف `'furniture'`.
   - تسجيل الفئة الجديدة في `src/symbols/registry.ts` مع بيانات اللون والأيقونة والترجمة.
2. **الخطوة الثانية: تحسين محرك الرسم (Engine Smoothness & Zero-Lag Refactor)**
   - إضافة جدولة `requestAnimationFrame` في `src/engine/renderer.ts` لأحداث `mousemove` والتفاعل اللحظي.
   - تحسين خوارزمية الفحص في `src/engine/snap.ts` لتقليل الحسابات الرياضية للأجسام البعيدة عن الشاشة أو المؤشر.
   - ضبط ثبات طبقات الكانفس ومنع استدعاءات `destroyChildren()` المتكررة غير الضرورية أثناء السحب العابر.
3. **الخطوة الثالثة: تحديث الواجهة الرسومية (UI Integration)**
   - إضافة أيقونة وقسم الفرش في `src/ui/SymbolsCatalogModal.tsx`.
   - دعم التصفح والبحث السريع والفلترة لعناصر الفرش والأجهزة.
   - إضافة اختصارات سريعة في شريط الأدوات أو القوائم لسهولة الوصول.
4. **الخطوة الرابعة: فحص الجودة والتجميع (Verification & Compilation)**
   - تشغيل فحص الأخطاء والأنماط `lint_applet` و `compile_applet`.
   - التحقق من ثبات معدل الإطارات (60+ FPS) أثناء تحريك الكانفس ورسم الجدران ووضع قطع الفرش.
