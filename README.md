# مخططاتي — CAD Studio

منصة رسم هندسي ثنائي الأبعاد (2D CAD) للمخططات المعمارية والكهروميكانيكية (MEP) تعمل في المتصفح وكتطبيق سطح مكتب (Electron)، بواجهة عربية كاملة (RTL).

> Professional Architectural & MEP 2D CAD — React + TypeScript + Konva.

---

## الميزات

- **رسم معماري:** جدران بسماكات قابلة للضبط، أبواب ونوافذ مرتبطة بالجدران، أبعاد (Dimensions)، ملاحظات نصية.
- **أنظمة MEP:** مكتبة رموز (كهرباء، سباكة، تكييف، إطفاء حريق، فرش وأجهزة) + رموز مخصصة، ومسارات كابلات/مواسير/دكت مع حساب الأطوال.
- **الدقة:** التقاط (نهايات، منتصف، على الجدار، رموز، شبكة)، قفل زوايا قطبي 45°/90° (Shift)، إدخال طول الجدار رقمياً، معايرة المقياس على طريقة SketchUp.
- **القياس:** شريط قياس، مساحة ومحيط مضلع (Shoelace).
- **الإدارة:** طبقات (إظهار/قفل/شفافية/لون)، لوحات متعددة (Sheets)، تراجع وإعادة (Command Pattern)، تحديد مفرد/مربع/متعدد، نسخ/قص/لصق/تكرار، تحريك بالأسهم.
- **الاستيراد والتصدير:** JSON للمشروع، DXF (AutoCAD)، PNG / PDF، جدول كميات BOQ.
- **مساعد هندسي ذكي** (اختياري) عبر Gemini API من جهة الخادم.
- **دقة بنمط AutoCAD:** إدخال إحداثيات `x,y` / `@dx,dy` / `@طول<زاوية`، التعامد F8، تتبع المحاذاة، التقاط التقاطع والعمودي، ووصل أركان الجدران.
- **أوامر التحرير بنقطة أساس:** نقل، نسخ متعدد، تدوير، تحجيم، مرآة، مصفوفة مستطيلة ودائرية، إزاحة متوازية، قص (Trim) وتمديد (Extend) للجدران والخطوط المفتوحة والمغلقة، ومحاذاة/توزيع العناصر المحددة (زر أيمن أو شريط الأوامر).
- **شريط الأوامر:** اكتب اسم الأمر بالعربية أو الإنجليزية (`/` للتركيز)، و`Enter` يكرر آخر أمر، مع اختصارات قابلة للتخصيص من الإعدادات.
- **الحفظ:** IndexedDB بلا حد حجم + نسخ احتياطية تلقائية (آخر 10) + إصدار صيغة وترحيل وتحقق عند الفتح.
- **استيراد DXF كامل:** الطبقات وألوانها، الكتل والإدراجات، الأقواس والدوائر، والخطوط الحرة غير الجدارية.
- **أداء المخططات الكبيرة:** تكبير/تحريك بلقطة نقطية مؤقتة + اقتطاع نطاق الرؤية (Culling) + مستويات تفاصيل (LOD) + رسم مجمّع فوق 1,500 عنصر مرئي + فهرس مكاني للالتقاط.
- **اللمس:** تكبير بالقرص وتحريك بإصبعين (Pinch / Two‑finger pan).

## البيئة المطلوبة

| المكوّن | الإصدار |
| --- | --- |
| Node.js | 22 أو أحدث (يُنصح بـ 22 LTS) |
| npm | 10+ |
| (اختياري) مفتاح Gemini API | للمساعد الذكي فقط |

التقنيات: React 19 · TypeScript · Vite · Tailwind CSS 4 · Konva · jsPDF · Express (خادم التطوير/الإنتاج) · Electron (سطح المكتب).

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local      # ثم ضع GEMINI_API_KEY إن أردت المساعد الذكي
npm run dev                     # خادم Express + Vite على http://localhost:3000
```

بدون خادم (واجهة فقط، المساعد الذكي يعمل بوضع احتياطي):

```bash
npx vite            # تطوير
npm run build       # بناء إلى dist/
npm run preview     # معاينة البناء
```

## الاختبارات

```bash
npm run typecheck     # فحص الأنواع
npm test              # اختبارات الوحدات (Vitest): التحويلات، الترحيل، DXF، الالتقاط، النموذج، الأوامر، وصل الجدران
npx playwright install chromium   # مرة واحدة
npm run test:e2e      # اختبارات التفاعل في المتصفح (Playwright): الرسم، الدقة، التحرير، الحفظ الكبير، DXF
```

لاستخدام Chrome المثبت بدلاً من متصفح Playwright: `CHROME_PATH=/usr/bin/google-chrome npm run test:e2e`.
تعمل كل الاختبارات تلقائياً على GitHub Actions مع كل طلب دمج (`.github/workflows/ci.yml`).

## تطبيق سطح المكتب (Windows)

```bash
npm run electron:dev        # تشغيل Electron محلياً
npm run build:win:portable  # ملف exe محمول
npm run build:win           # مثبّت NSIS + محمول
```

التفاصيل في [`ELECTRON_GUIDE.md`](ELECTRON_GUIDE.md).

**البناء السحابي بدون جهاز ويندوز:** سير العمل `.github/workflows/windows.yml` يبني الملفين على خادم ويندوز:
- يدوياً: تبويب **Actions** ← **Windows build** ← **Run workflow**، ثم نزّل `cad-studio-windows` من أسفل صفحة التشغيل.
- عند إصدار نسخة: `git tag v1.1.0 && git push origin v1.1.0` فتُنشأ مسودة إصدار في **Releases** مرفق بها `CAD Studio-Setup-<version>.exe` و`CAD Studio-<version>-portable.exe`.

> الملفات غير موقّعة رقمياً، لذا قد يظهر تحذير SmartScreen عند أول تشغيل («مزيد من المعلومات» ← «تشغيل على أي حال»).

## الاختصارات الأساسية

| المفتاح | الوظيفة |
| --- | --- |
| `V` / `1` | تحديد (تكرار V يبدّل: مفرد ← مربع ← متعدد) |
| `W` | جدار · `D` باب · `N` نافذة · `M` بُعد · `8` قياس · `A` مساحة · `R` مسار · `S` رمز · `T` نص · `H` تحريك |
| `Shift` | قفل الزاوية أثناء الرسم / إضافة للتحديد |
| `Space` + سحب، أو الزر الأوسط | تحريك اللوحة |
| عجلة الفأرة | تكبير حول المؤشر |
| `Ctrl+Z` / `Ctrl+Y` | تراجع / إعادة |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` `Ctrl+D` | نسخ / قص / لصق / تكرار |
| `Ctrl+A` · `Delete` · الأسهم | تحديد الكل · حذف · إزاحة (مع Shift خطوة أكبر) |
| `Ctrl+S` · `Ctrl+Shift+S` · `Ctrl+O` | حفظ · حفظ باسم · فتح |
| `Ctrl+E` / `Ctrl+P` · `Ctrl+B` · `Ctrl+L` · `Ctrl+K` | تصدير · جدول الكميات · الطبقات · مكتبة الرموز |
| `Esc` | إلغاء الرسم الحالي |
| `F8` | وضع التعامد (Ortho) |
| `/` | التركيز على شريط الأوامر (جدار، نقل/m، نسخ/co، تدوير/ro، مرآة/mi، مصفوفة/ar، دائرية/polar، إزاحة/o، قص/tr، تمديد/ex، محاذاة all/alr/alt/alb/alcx/alcy، توزيع dih/div، ملاءمة/z…) |
| `Enter` (على اللوحة) | تكرار آخر أمر |
| أرقام أثناء الرسم | إدخال طول أو إحداثيات بالمتر |

## بنية المشروع

```
src/
  App.tsx              ربط الواجهة بالمحرك والنموذج
  engine/              المحرك: renderer (Konva) + render/ interaction/ tools/ export/ geometry/،
                       camera، snap، grid، commands، dxfEngine/dxfImport، exportEngine، aiInspector، liveStatus
  model/               نموذج البيانات: project، history (Undo/Redo)، types، transforms، schema، storage (IndexedDB)، lastUsedSettings
  symbols/             مكتبات الرموز حسب التخصص + الرموز المخصصة
  ui/                  مكونات الواجهة (أشرطة، لوحات، نوافذ منبثقة)
electron/              العملية الرئيسية و preload لتطبيق سطح المكتب
server.ts              خادم Express (Vite middleware + مسار /api/ai-assistant)
```

## ملاحظات

- الحفظ في المتصفح يتم في IndexedDB (بلا حد عملي) مع نسخة في localStorage، والنسخ الاحتياطية من **الإعدادات**. لنقل المشروع لجهاز آخر استخدم «حفظ باسم» أو «تصدير JSON».
- لا ترفع ملف `.env.local` إلى المستودع؛ هو مستبعد في `.gitignore`.
